## 💻 Frontend Overview

This directory contains the production **Next.js 16** App Router frontend application for **[ConU Planner](https://www.conuplanner.com)**.

* **Framework:** Next.js 16 (App Router, Turbopack)
* **UI Library:** React 19, TypeScript
* **State & Drag-and-Drop:** `@dnd-kit/core`, `@dnd-kit/sortable`
* **Graph Visualization:** `@xyflow/react` (ReactFlow) + Dagre DAG layout
* **Styling:** Tailwind CSS, Framer Motion, GSAP, Lenis
* **Cloud & Auth:** Firebase Firestore, Clerk Auth

### Quickstart
```bash
npm install
npm run dev
```
Runs the local development server at `http://localhost:3000`.
